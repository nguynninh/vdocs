# Documents

APIs for creating, reading, updating, and deleting documents in VDocs.

## List documents

```
GET /itr/documents
```

**Query params**

| Name | Type | Description |
| --- | --- | --- |
| `page` | number | Current page (default `1`) |
| `limit` | number | Items per page (default `20`) |

## Create a document

```
POST /itr/documents
```

**Body**

```json
{
  "title": "My document",
  "content": ""
}
```

## Get document details

```
GET /itr/documents/{id}
```

## Update a document

```
PATCH /itr/documents/{id}
```

## Delete a document

```
DELETE /itr/documents/{id}
```
