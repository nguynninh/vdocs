# Authentication

vdocs-server uses Bearer Tokens to authenticate API requests.

## Getting a token

```
POST /itr/auth/login
```

**Body**

```json
{
  "email": "user@example.com",
  "password": "your-password"
}
```

**Response**

```json
{
  "success": true,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "expiresIn": 3600
  }
}
```

## Using the token

Attach the token to the `Authorization` header of subsequent requests:

```
Authorization: Bearer <token>
```
