# Required update notes



1. Google Play 16 KB Compatibility Requirement:
Starting August 31, 2026, all new apps and updates to existing apps submitted to Google Play that target      Android 16 \(or higher\) must support 16 KB page size on 64\-bit devices\.

For more details, see: 
     [https://developer\.android\.google\.cn/guide/practices/page\-sizes?hl=zh\_cn\#compile\-16\-kb\-alignment](https://developer.android.google.cn/guide/practices/page-sizes?hl=zh_cn#compile-16-kb-alignment)

3. If your development version of unity is 2017\.1 or later please read\.
https://discussions\.unity\.com/t/unity\-platform\-protection\-take\-immediate\-action\-to\-protect\-your\-games\-and\-apps/1688031

# Integrate SDK

## Initialize the SDK \(Required\)

implements callback AuthenticationListener, PaymentListener into your activity

Change environment variables : 
Dev  \-\> vLiveSdkGame\.setEnvironment\(EnvironmentSdk\.Development\);
Prod \-\> vLiveSdkGame\.setEnvironment\(EnvironmentSdk\.Production\);

```java
public class MainActivity extends Activity implements AuthenticationListener, PaymentListener {
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        requestWindowFeature(Window.FEATURE_NO_TITLE);
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
        getWindow().setFlags(WindowManager.LayoutParams.FLAG_FULLSCREEN, WindowManager.LayoutParams.FLAG_FULLSCREEN);

        // this config sdk game
        VLiveSdkGame vLiveSdkGame = VLiveSdkGame.getInstance();
        vLiveSdkGame.setEnvironment(EnvironmentSdk.Development);
        vLiveSdkGame.setActivity(this);
        vLiveSdkGame.setAuthenticationListener(this);
        vLiveSdkGame.setPaymentListener(this);


    }

    @Override
    public void onLoginSuccessful(UserInfo userInfo, String accessToken, String refreshToken, String idToken) {
    
    }

    @Override
    public void onLogoutSuccessful() {

    }

    @Override
    public void onPayProductSuccess(String orderId,String productId) {

    }

    @Override
    public void onPayProductError(String error) {

    }
}
```

2. Configuration when rotating screen

```java
@Override
public void onConfigurationChanged(@NotNull Configuration newConfig) {

   VLiveSdkGame.getInstance().resetFloatingButton();
}
```

## SDK function

### Authentication \(Required\)

#### Login 

Function of the function:

- Open the login interface when not logged in

- Log in when the user reopens the application

- Log out when the login session ends\.

You should call this function when clicking the game's start button\.

```java
VLiveSdkGame.getInstance().login(); 
```

Successful login will call onLoginSuccessful



#### Logout

Successful logout will call onLogoutSuccessful

```java
VLiveSdkGame.getInstance().logout();
```



### Payment \(Required\)

Note: You cannot test payments unless your app is installed via Google Play's internal testing track\.

To perform payment testing, we require the AAB \(Android App Bundle\) version\.

#### List of In\-App Purchase \(IAP\) Game Packages \( Optional \)

This function will return a list of top\-up packages similar to the Pricelist\.xlsx file\.
Note: This is an optional function that can be called if needed\.

```java
List<ProductInfo> listProduct = VLiveSdkGame.getInstance().getListProduct();
```

Model ProductInfo

```java
String productId = productInfo.getProductId(); // vn.vplay.game.t001a.029
String productName = productInfo.getProductName(); // 20 Ngân Phiếu
```



#### Buy Packages \(Required\)

If you want to buy an item, please call this function:

The input parameters can be taken from the list above or entered manually\.

```java
String productId = "vn.vplay.game.t001a.029"; 
String characterId = "324132321";
String serverId  = "123";
VLiveSdkGame.getInstance().payProduct(productId,characterId,serverId);
```



### Tracking Event \(Required\)

Note: Tracking functions intended for marketing purposes should be used strictly according to the defined flow\. 

#### These events are required to be integrated\.



#### Event Parameter Details

1. Tracking Patch Start \(Required\)
Description: Should be called when the resource download starts\.
Event Name: af\_patch\_start

```java
String patchVersion = "1.1.23"; // or empty
double patchSizeMb = 550.5; // or 0
VLiveSdkGame.getInstance().trackingPatchStart(patchVersion,patchSizeMb);
```



2. Tracking Patch Error \(Required\)
Description: Should be called when an error occurs during resource download\.
Event Name: af\_patch\_error

```java
String cdnIp = "122.56.12.188"; // or empty
String errorCode = "404_NOT_FOUND"; // or empty
String failedUrl =  "https://cdn.game.com/patch/v120.zip"; // or empty
VLiveSdkGame.getInstance().trackingPatchError(cdnIp, errorCode,failedUrl);
```



3. Tracking Patch Success \(Required\)
Description: Should be called after all resources have been successfully downloaded\.
Event Name: af\_patch\_success

```java
int timeDownloadSecond = 32; // or 0
String cdnIp = "122.56.12.188"; // or empty
double patchSizeMb = 500.5; // or 0
VLiveSdkGame.getInstance().trackingPatchSuccess(timeDownloadSecond,cdnIp,patchSizeMb);
```



4. Tracking Extract Start \(Required\)
Description: Should be called when the resource extraction process starts\.
Event Name: af\_extract\_started

```java
int totalFiles = 400;// or 0
double totalSizeMb = 500.5;// or 0
VLiveSdkGame.getInstance().trackingExtractStart(totalFiles,totalSizeMb);
```



5. Tracking Extract Finished \(Required\)
Description: Should be called after all resources have been successfully extracted\.
Event Name: af\_extract\_finished

```java
int timeExtractSecond = 32; // or 0
String resultCode = "success" // or Errror String (ex: out_of_storage)
VLiveSdkGame.getInstance().trackingExtractFinished(timeExtractSecond,resultCode);
```

6. Tracking Show Start Game \( Required\)
Description: Should be called after the game start screen is displayed\.
Event Name: af\_show\_start\_game

```java
VLiveSdkGame.getInstance().trackingEvent(EventGameTracking.EVENT_SHOW_START_GAME);
```

7. Tracking Server Selected \( Required\)
Description: Called after the user confirms a server selection and enters the game flow\.
Event Name: af\_server\_select

```java
String serverName = "ServerName"; // Required Not empty, Not Null 
String serverId = "23232"; // Required Not empty, Not Null 
VLiveSdkGame.getInstance().trackingServerSelected(serverName,serverId);
```

8. Tracking Character Creation Start \( Required\)
Description: Should be called when the character creation screen becomes visible to the user\.
Event Name: af\_char\_create\_start

```java
VLiveSdkGame.getInstance().trackingCharacterCreationStart();
```



9. Tracking Character Creation Error \( Required\)
Description: Should be called when an error occurs during character creation\.
Event Name: af\_char\_create\_error

```java
String characterNameError = "Hao Thien"; // or empty
String errorMessage = "NAME_DUPLICATED"; // or empty
VLiveSdkGame.getInstance().trackingCharacterCreateError(characterNameError, errorMessage);
```



10. Tracking Character Creation Complete \( Required\)
Description: Should be called after the character creation process is completed successfully\.
Event Name: af\_char\_create\_success

```java
String characterName = "CharacterName"; // Required Not empty, Not Null 
String characterId = "23232"; // Required Not empty, Not Null 
VLiveSdkGame.getInstance().trackingCharacterCreationComplete(characterName,characterId);
```



11. Tracking Character Selected \( Required\)
Description: Should be called after the user selects an existing character and enters the game\.
Event Name: af\_char\_select

```java
String characterName = "CharacterName"; // Required Not empty, Not Null 
String characterId = "23232"; // Required Not empty, Not Null 
String characterLevel = "1"; // Required Not empty, Not Null 
VLiveSdkGame.getInstance().trackingCharacterSelected(characterName,characterId,characterLevel);
```



12. Tracking Enter Game \( Required\)
Description: Should be called after the user has selected a character and started entering the game\.
Event Name: af\_enter\_gameplay



```java
VLiveSdkGame.getInstance().trackingEvent(EventGameTracking.EVENT_GAME_ENTER);
```



13. Map User \( Required\)
Description: Should be called after the user has selected a character and started entering the game\.
Event Name: af\_level\_achievement

```java
String characterName = "CharacterName"; // or empty
String characterId = "23232"; // Required Not empty, Not Null 
String characterLevel = "2"; // Required Not empty, Not Null 
String serverName = "ServerName";// or empty
String serverId = "324232";// Required Not empty, Not Null 
VLiveSdkGame.getInstance().mapUser(characterName, characterId, characterLevel, serverName, serverId);
```



14. Character Level Up \( Required\)
Description: Should be called when the user successfully levels up\.
Event Name: af\_level\_achievement
Event Name: af\_vip\_achievement

```java
String characterName = "CharacterName"; // or empty
String characterId = "23232";// Required Not empty, Not Null 
String characterLevel = "2"; // Required Not empty, Not Null 
String serverName = "ServerName"; // or empty
String serverId = "324232"; // or empty
String vip = "1"; // Required Not empty, Not Null 
VLiveSdkGame.getInstance().levelUpUser(characterName, characterId, characterLevel, serverName, serverId,vip);
```



15. Tracking Load Map Game \( Required\)
Description: Should be called after the map has been fully loaded\.

```java
String mapId = "newbie_village"; // or empty
int timeLoadSecond = 32; // or 0
int fpsAtStart = 60; // or 0
VLiveSdkGame.getInstance().trackingMapLoad(mapId, timeLoadSecond, fpsAtStart);
```

16. Custom Events
Description: Use for other custom events

```java
String eventName = "Event_Name";
VLiveSdkGame.getInstance().trackingEvent(eventName);

// Or
String eventName = "Event_Name";
JsonObject jsonObject = new JsonObject();
jsonObject.addProperty("stringValue", "Hello");
jsonObject.addProperty("intValue", 42);
VLiveSdkGame.getInstance().trackingEvent(eventName,jsonObject);
```
