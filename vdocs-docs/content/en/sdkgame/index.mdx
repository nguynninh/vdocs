# Introduction

**VDocs** is a framework built on top of Next.js that lets you build content-focused websites. It has all the great features of Next.js, plus extra power to easily create Markdown-based content.

## FAQ

The VDocs FAQ is a collection of helpful questions and answers about the project. If you have a question that isn't answered here, please <a href="https://github.com/">open a discussion ↗</a>.

<details className="faq-item">
  <summary>Can I use VDocs with the Next.js <code>pages</code> router?</summary>
  <p>VDocs 4 only works with the <code>app</code> router. Older versions support the <code>pages</code> router.</p>
</details>

<details className="faq-item">
  <summary>Can I use X with VDocs?</summary>
  <p>Yes, with most React libraries. VDocs is still a Next.js plugin, so familiar integrations all work.</p>
</details>

<details className="faq-item">
  <summary>How do I add live-editable code components to VDocs?</summary>
  <p>You can use libraries like Sandpack or react-live directly in MDX.</p>
</details>
