# Update play_time event logic

## Purpose

## Requirements

1. After a successful login, fire periodically at 30s, 1m, 3m, 5m, 15m, 30m, 1 hour, then every 1 hour after that.

2. If a character is created successfully, reset play time = 0 and recalculate per (1).

3. If the user keeps playing past midnight, play time will automatically reset to 0 at 00:00 UTC+7 and recalculate per (1).

4. If the user goes to the home screen -> pause play_time -> the user returns to the game without being logged out -> playtime counting resumes from the pause point.

5. If the user goes to the home screen and then re-enters the game after being logged out, counting restarts from (1).
