Currently, the events sent to Vlive have no parameters or very few, per the [Hub Logs Collection](https://vtvlivevn.sg.larksuite.com/docx/Dni9d8xqNo6wEjxVNMQuWBk7sFf) document.
New events that have not yet been applied need to be added and standardized.

Default parameters sent when an event is sent to the vlive tracking game SDK:

`deviceId`: Device identifier ID

`deviceModel`: Device model name

`deviceBrand`: Device brand

`deviceFullInfoJson`: Full device information in JSON format

`deviceOs`: Device OS name (e.g. Android, iOS)

`deviceOsVersion`: Device OS version

`appClientId`: App client ID

`appId`: App ID

`appName`: App name

`appCode`: App code

`appPackage`: App package name (e.g. `com.example.app`)

`appVersion`: App version

`appSdkVersion`: App SDK version

`deviceFullInfoJson` includes the following parameters:

`width`: Screen width (px)

`height`: Screen height (px)

`density_dpi`: Screen pixel density (DPI)

`density`: Screen scale ratio (e.g. 2.0, 3.0)

`serial`: Device serial number

`model`: Device model name (e.g. Pixel 8, SM-A525F)

`id`: OS build ID

`manufacture`: Device manufacturer (Samsung, Xiaomi, Oppo...)

`brand`: Device brand

`type`: OS build type (`user`, `userdebug`, `eng`)

`user`: User name used to build the OS

`base`: First Android platform version code (usually 1)

`incremental`: OS incremental build number

`sdk`: Android API Level (e.g. 34)

`board`: Device board/hardware name

`host`: Host name used to build the OS

`fingerprint`: Unique identifier string of the device/ROM build

`version_code`: Android version shown to the user (e.g. 14)
