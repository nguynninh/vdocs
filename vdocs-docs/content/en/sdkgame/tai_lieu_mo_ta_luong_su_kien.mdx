# Event Flow Description

| **Event Name** | **Location** | **Flow Description** | **Note: event used by MKT for ad optimization** |

| af_complete_registration | BackEnd | Registration completed | |

| af_play_time | SDK Game | Game play time (30s, 1m, 3m, 5m, 15m, 30m, 1h, 2h, 3h... +1h) | Measures user quality |
| af_cancel_purchase | SDK Game | Cancel IAP purchase | |
| af_app_launch | SDK Game | Game launch | Parameter for measuring NRU rate |

| af_purchase_point_iap | BackEnd | Top-up in-game on mobile device triggers this | |
| af_server_iap_purchase | BackEnd | Purchase via app | |
| af_purchase | BackEnd | Purchase | Measures ad revenue |
| af_registration | BackEnd | Log in with a new account into the game | Measures NRU |
| af_server_registration | BackEnd | | Measures NRU |
| af_payment_success | SDK Game | Payment successful in game | |
| af_open_payment_screen | SDK Game | Open payment screen in game | |

| af_character_creation_started | SDK Game, Partner | Started character creation | |
| af_character_creation_finished | SDK Game, Partner | Finished character creation | Measures successful game-entry rate (character created) |
| af_resource_started | SDK Game, Partner | Started resource download | Measures drop-off rate during resource download |

| af_upgrade_version_success | SDK Game | User updates the game | |
