# Mã lỗi

Khi xảy ra lỗi, API trả về `success: false` kèm mã lỗi và mô tả.

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "Token không hợp lệ hoặc đã hết hạn"
  }
}
```

## Bảng mã lỗi

| Mã | HTTP Status | Mô tả |
| --- | --- | --- |
| `UNAUTHORIZED` | 401 | Token không hợp lệ hoặc đã hết hạn |
| `FORBIDDEN` | 403 | Không có quyền truy cập tài nguyên |
| `NOT_FOUND` | 404 | Không tìm thấy tài nguyên |
| `VALIDATION_ERROR` | 422 | Dữ liệu gửi lên không hợp lệ |
| `INTERNAL_ERROR` | 500 | Lỗi hệ thống |
