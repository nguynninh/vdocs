# Tài liệu (Documents)

Các API để tạo, đọc, cập nhật và xóa tài liệu trong VDocs.

## Danh sách tài liệu

```
GET /itr/documents
```

**Query params**

| Tên | Kiểu | Mô tả |
| --- | --- | --- |
| `page` | number | Trang hiện tại (mặc định `1`) |
| `limit` | number | Số lượng mỗi trang (mặc định `20`) |

## Tạo tài liệu mới

```
POST /itr/documents
```

**Body**

```json
{
  "title": "Tài liệu của tôi",
  "content": ""
}
```

## Lấy chi tiết tài liệu

```
GET /itr/documents/{id}
```

## Cập nhật tài liệu

```
PATCH /itr/documents/{id}
```

## Xóa tài liệu

```
DELETE /itr/documents/{id}
```
