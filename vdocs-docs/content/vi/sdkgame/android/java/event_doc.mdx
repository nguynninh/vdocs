## 2. Sự kiện gửi lên Vlive Tracking (Hub Logs Collection)

Hiện tại các sự kiện gửi lên Vlive đang không có tham số hoặc có ít tham số theo tài liệu Hub Logs Collection. Các sự kiện mới chưa được apply cần bổ sung và thống nhất lại.

### Tham số mặc định khi gửi sự kiện lên sdk vlive tracking game

- `deviceId` : ID định danh thiết bị
- `deviceModel` : Tên model thiết bị
- `deviceBrand` : Thương hiệu thiết bị
- `deviceFullInfoJson` : Thông tin đầy đủ của thiết bị dạng JSON
- `deviceOs` : Tên hệ điều hành thiết bị (ví dụ: Android, iOS)
- `deviceOsVersion` : Phiên bản hệ điều hành thiết bị
- `appClientId` : ID client của ứng dụng
- `appId` : ID ứng dụng
- `appName` : Tên ứng dụng
- `appCode` : Mã ứng dụng
- `appPackage` : Tên package của ứng dụng (ví dụ: `com.example.app`)
- `appVersion` : Phiên bản ứng dụng
- `appSdkVersion` : Phiên bản SDK của ứng dụng

`deviceFullInfoJson` bao gồm các tham số dưới đây :

- `width` : Chiều ngang màn hình (px)
- `height` : Chiều dọc màn hình (px)
- `density_dpi` : Mật độ điểm ảnh màn hình (DPI)
- `density` : Tỷ lệ scale màn hình (ví dụ: 2.0, 3.0)
- `serial` : Số serial của thiết bị
- `model` : Tên model thiết bị (ví dụ: Pixel 8, SM-A525F)
- `id` : ID bản build của hệ điều hành
- `manufacture` : Nhà sản xuất thiết bị (Samsung, Xiaomi, Oppo...)
- `brand` : Thương hiệu thiết bị
- `type` : Loại bản build hệ điều hành (`user`, `userdebug`, `eng`)
- `user` : Tên user dùng để build hệ điều hành
- `base` : Mã version nền tảng Android đầu tiên (thường là 1)
- `incremental` : Mã build tăng dần của hệ điều hành
- `sdk` : API Level Android (ví dụ: 34)
- `board` : Tên bo mạch/phần cứng thiết bị
- `host` : Tên máy chủ dùng để build hệ điều hành
- `fingerprint` : Chuỗi định danh duy nhất của thiết bị/bản ROM
- `version_code` : Phiên bản Android hiển thị cho người dùng (ví dụ: 14)
