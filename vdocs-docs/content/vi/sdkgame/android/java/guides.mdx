## Yêu cầu Proguard

BẮT BUỘC đối với ứng dụng Android có sử dụng Proguard. Để tránh làm rối (obfuscate) SDK khi sử dụng Proguard, hãy đảm bảo cấu hình sau được thêm vào:



```java
-keep class vlive.sdk.game.** { *; }

```

## Khởi tạo SDK (Bắt buộc)

Triển khai (implement) callback AuthenticationListener, PaymentListener vào activity của bạn

Thay đổi biến môi trường : 
Dev  -> vLiveSdkGame.setEnvironment(EnvironmentSdk.Development);
Prod -> vLiveSdkGame.setEnvironment(EnvironmentSdk.Production);

```java
public class MainActivity extends Activity implements AuthenticationListener, PaymentListener {
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        requestWindowFeature(Window.FEATURE_NO_TITLE);
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
        getWindow().setFlags(WindowManager.LayoutParams.FLAG_FULLSCREEN, WindowManager.LayoutParams.FLAG_FULLSCREEN);

        // this config sdk game
        VLiveSdkGame vLiveSdkGame = VLiveSdkGame.getInstance();
        vLiveSdkGame.setEnvironment(EnvironmentSdk.Development);
        vLiveSdkGame.setActivity(this);
        vLiveSdkGame.setAuthenticationListener(this);
        vLiveSdkGame.setPaymentListener(this);


    }

    @Override
    public void onLoginSuccessful(UserInfo userInfo, String accessToken, String refreshToken, String idToken) {
    
    }

    @Override
    public void onLogoutSuccessful() {

    }

    @Override
    public void onPayProductSuccess(String orderId,String productId) {

    }

    @Override
    public void onPayProductError(String error) {

    }
}
```

## Chức năng SDK

### Xác thực (Bắt buộc)

#### Đăng nhập 

Chức năng của hàm:

- Mở giao diện đăng nhập khi chưa đăng nhập

- Đăng nhập khi người dùng mở lại ứng dụng

- Đăng xuất khi phiên đăng nhập kết thúc.

Bạn nên gọi hàm này khi nhấn nút bắt đầu (start) của game.

```java
VLiveSdkGame.getInstance().login(); 
```

Đăng nhập thành công sẽ gọi onLoginSuccessful



#### Đăng xuất

Đăng xuất thành công sẽ gọi onLogoutSuccessful


### Tracking sự kiện (Bắt buộc)

Lưu ý: Các hàm tracking phục vụ mục đích marketing cần được sử dụng đúng theo quy trình đã định. 

#### Các sự kiện sau bắt buộc phải được tích hợp.



#### Chi tiết tham số sự kiện

1. Tracking Patch Start (Bắt buộc)
Mô tả: Nên được gọi khi bắt đầu quá trình tải tài nguyên (resource).
Tên sự kiện: af_patch_start

```java
String patchVersion = "1.1.23"; // or empty
double patchSizeMb = 550.5; // or 0
VLiveSdkGame.getInstance().trackingPatchStart(patchVersion,patchSizeMb);
```



2. Tracking Patch Error (Bắt buộc)
Mô tả: Nên được gọi khi xảy ra lỗi trong quá trình tải tài nguyên.
Tên sự kiện: af_patch_error

```java
String cdnIp = "122.56.12.188"; // or empty
String errorCode = "404_NOT_FOUND"; // or empty
String failedUrl =  "https://cdn.game.com/patch/v120.zip"; // or empty
VLiveSdkGame.getInstance().trackingPatchError(cdnIp, errorCode,failedUrl);
```



3. Tracking Patch Success (Bắt buộc)
Mô tả: Nên được gọi sau khi tất cả tài nguyên đã được tải thành công.
Tên sự kiện: af_patch_success

```java
int timeDownloadSecond = 32; // or 0
String cdnIp = "122.56.12.188"; // or empty
double patchSizeMb = 500.5; // or 0
VLiveSdkGame.getInstance().trackingPatchSuccess(timeDownloadSecond,cdnIp,patchSizeMb);
```



4. Tracking Extract Start (Bắt buộc)
Mô tả: Nên được gọi khi bắt đầu quá trình giải nén tài nguyên.
Tên sự kiện: af_extract_started

```java
int totalFiles = 400;// or 0
double totalSizeMb = 500.5;// or 0
VLiveSdkGame.getInstance().trackingExtractStart(totalFiles,totalSizeMb);
```



5. Tracking Extract Finished (Bắt buộc)
Mô tả: Nên được gọi sau khi tất cả tài nguyên đã được giải nén thành công.
Tên sự kiện: af_extract_finished

```java
int timeExtractSecond = 32; // or 0
String resultCode = "success" // or Errror String (ex: out_of_storage)
VLiveSdkGame.getInstance().trackingExtractFinished(timeExtractSecond,resultCode);
```

6. Tracking Show Start Game (Bắt buộc)
Mô tả: Nên được gọi sau khi màn hình bắt đầu game được hiển thị.
Tên sự kiện: af_show_start_game

```java
VLiveSdkGame.getInstance().trackingEvent(EventGameTracking.EVENT_SHOW_START_GAME);
```

7. Tracking Server Selected (Bắt buộc)
Mô tả: Được gọi sau khi người dùng xác nhận chọn server và bắt đầu vào luồng game.
Tên sự kiện: af_server_select

```java
String serverName = "ServerName"; // Required Not empty, Not Null 
String serverId = "23232"; // Required Not empty, Not Null 
VLiveSdkGame.getInstance().trackingServerSelected(serverName,serverId);
```

8. Tracking Character Creation Start (Bắt buộc)
Mô tả: Nên được gọi khi màn hình tạo nhân vật hiển thị cho người dùng.
Tên sự kiện: af_char_create_start

```java
VLiveSdkGame.getInstance().trackingCharacterCreationStart();
```



9. Tracking Character Creation Error (Bắt buộc)
Mô tả: Nên được gọi khi xảy ra lỗi trong quá trình tạo nhân vật.
Tên sự kiện: af_char_create_error

```java
String characterNameError = "Hao Thien"; // or empty
String errorMessage = "NAME_DUPLICATED"; // or empty
VLiveSdkGame.getInstance().trackingCharacterCreateError(characterNameError, errorMessage);
```



10. Tracking Character Creation Complete (Bắt buộc)
Mô tả: Nên được gọi sau khi quá trình tạo nhân vật hoàn tất thành công.
Tên sự kiện: af_char_create_success

```java
String characterName = "CharacterName"; // Required Not empty, Not Null 
String characterId = "23232"; // Required Not empty, Not Null 
VLiveSdkGame.getInstance().trackingCharacterCreationComplete(characterName,characterId);
```



11. Tracking Character Selected (Bắt buộc)
Mô tả: Nên được gọi sau khi người dùng chọn một nhân vật đã có sẵn và vào game.
Tên sự kiện: af_char_select

```java
String characterName = "CharacterName"; // Required Not empty, Not Null 
String characterId = "23232"; // Required Not empty, Not Null 
String characterLevel = "1"; // Required Not empty, Not Null 
VLiveSdkGame.getInstance().trackingCharacterSelected(characterName,characterId,characterLevel);
```



12. Tracking Enter Game (Bắt buộc)
Mô tả: Nên được gọi sau khi người dùng đã chọn nhân vật và bắt đầu vào game.
Tên sự kiện: af_enter_gameplay



```java
VLiveSdkGame.getInstance().trackingEvent(EventGameTracking.EVENT_GAME_ENTER);
```



13. Map User (Bắt buộc)
Mô tả: Nên được gọi sau khi người dùng đã chọn nhân vật và bắt đầu vào game.
Tên sự kiện: af_level_achievement

```java
String characterName = "CharacterName"; // or empty
String characterId = "23232"; // Required Not empty, Not Null 
String characterLevel = "2"; // Required Not empty, Not Null 
String serverName = "ServerName";// or empty
String serverId = "324232";// Required Not empty, Not Null

```



14. Character Level Up (Bắt buộc)
Mô tả: Nên được gọi khi người dùng lên cấp (level up) thành công.
Tên sự kiện: af_level_achievement
Tên sự kiện: af_vip_achievement

```java
String characterName = "CharacterName"; // or empty
String characterId = "23232";// Required Not empty, Not Null 
String characterLevel = "2"; // Required Not empty, Not Null
```

15. Tracking Load Map Game (Bắt buộc)
Mô tả: Nên được gọi sau khi bản đồ (map) đã được tải xong hoàn toàn.

```java
String mapId = "newbie_village"; // or empty
int timeLoadSecond = 32; // or 0
int fpsAtStart = 60; // or 0
VLiveSdkGame.getInstance().trackingMapLoad(mapId, timeLoadSecond, fpsAtStart);
```
