## Quy trình cấu hình

1. Cấu hình trên Hub

    Sau khi cấu hình trên hub thành công và kiểm tra bằng cách copy data này vào sdk để kiểm tra các trường có đúng không thì hãy cấu hình nó lên firebase remote config giống như các game khác.

![image.png](/images/sdkgame/dev_config/image-8.png)

    1. Global

        Áp dụng cho tất cả các ứng dụng được tạo tự động không cần sửa trừ khi sai số hãy báo cho bên BE sửa. Giá trị mặc định là 0

    2. App

        Áp dụng cho tất cả các package kể cả iOS, tham số lấy ở appId

![image.png](/images/sdkgame/dev_config/image-6.png)

    1. Package

        Áp dụng cho package duy nhất lấy ở packageId

![image.png](/images/sdkgame/dev_config/image-10.png)

    2. Tham số cấu hình danh sách

2. Cấu hình trên firebase

    1. Cấu hình ứng dụng

        Truy cập: Setting -> General -> Add app -> Điền package Id

        Sau khi tạo app **Đấm Trưởng Phòng** cập nhật cấu hình trên google cloud để bổ sung thông tin cho google-service.json

        Kiểm tra json tại: https://dandar3.github.io/android/google-services-json-to-xml.html

        Cần đủ như hình

![image.png](/images/sdkgame/dev_config/image.png)

    2. Cấu hình thông báo từ server

        Sau khi cấu hình đúng google-server.json vào app mẫu thì chắc chắn sẽ nhận được noti, có thể test trước bằng message của firebase

        Project Setting -> Services account

        Hãy đảm bảo chỉ tạo 1 lần duy nhất và lưu file này lại.

        Khi tạo cấu hình cho cả Android và iOS ở Hub và thử lại thông báo từ cấu hình của package trên hub

4. Cấu hình example

    Vui lòng tham khảo dự án khác

    - Đổi package name
    - Đổi tên dự án
    - Đổi thông tin ở string.xml
    - Đổi google-service.json
    - Đổi file vtvlive_config_sdk_game_defaults -> thông tin lấy từ hub
    - Đổi key để tải thư viện vào 2 sdk game và game tracking, tạo key accesstoken -> developer -> read-api và lưu lại

5. Quy trình test ví dụ mẫu

    1. Đăng nhập thường

        Thất bại -> Kiểm tra lại cấu hình hub và dự án mẫu xem có đúng package và thông tin được cấp -> Đúng thì báo bên BE xem đã cấu hình đăng nhập chưa

    2. Đăng ký và Quên Mật Khẩu

        Thất bại -> Mở Log nhật ký thấy báo package name không tồn tại ở recaptcha -> **Đấm Trưởng Phòng** cấu hình

        Thất bại -> Hiển thị dialog báo lỗi từ BE -> Thiết bị và mạng bị spam bởi recaptcha, sử dụng thiết bị và mạng 3G khác

    3. Đăng nhập google

        Xác thực thông tin thất bại.

        Nguyên nhân:

        -> Ứng dụng build chưa ký, hoặc chữ ký bị sai ở google cloud. Cần kiểm tra 3 chỗ Apk, google cloud, store phải chung chữ ký sha1

        ! Có thể GG login client ID trên hub đang set sai

    4. Đăng nhập facebook

        Báo lỗi không đăng nhập được.

        Ở chế độ develop:

        Kiểm tra lại thông tin của facebook trong app

        Sử dụng đúng tài khoản thử nghiệm để đăng nhập không

        Ở chế độ public:

        Kiểm tra facebook đã cấp quyền profile chưa -> Chưa có **Đấm Trưởng Phòng** xin quyền từ facebook cho dự án

    5. Kiểm tra sự kiện lên appsflyer

        Mở log đặt tag là appsflyer, nếu bắn lên báo lỗi package name không tồn tại **Đấm Trưởng Phòng**

    6. Kiểm tra thanh toán

        Muốn thanh toán được cần đẩy 1 bản lên thử nghiệm nội bộ sau đó cấu hình gói nạp trên store và hub

        Nếu không thanh toán được báo lỗi không xác định

        Kiểm tra apk đã truyền đúng tên gói nạp chưa.

        Nếu bên game đã truyền đúng tên gói nạp mà api BE trả về lỗi không xác định

        **Đấm Trưởng Phòng** để trưởng phòng báo bên Thanh toán bật trên production và cấu hình bật service trên google cloud.

        Khi bật cấu hình này cần lâu nhất là 1 ngày mới có thể thanh toán được

## Cấu hình store

1. Đăng ký ứng dụng

    Việc đăng ký cần được làm ngay vì cần tới 48h để review đăng ký tên gói.

    Sau khi hoàn thành dự án mẫu, tạo file theo đường dẫn

![store-register.png](/images/sdkgame/dev_config/store-register.png)

    Mã được lấy từ store khi đăng ký package name

    Sử dụng đúng keystore và build ra apk rồi đưa lên store để đăng ký package name

    Sau khi đăng ký package name thì mới có thể tạo ứng dụng đó trên store
