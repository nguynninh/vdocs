# 文档（Documents）

用于在 VDocs 中创建、读取、更新和删除文档的 API。

## 获取文档列表

```
GET /itr/documents
```

**查询参数**

| 名称 | 类型 | 说明 |
| --- | --- | --- |
| `page` | number | 当前页码（默认 `1`） |
| `limit` | number | 每页数量（默认 `20`） |

## 创建新文档

```
POST /itr/documents
```

**请求体**

```json
{
  "title": "我的文档",
  "content": ""
}
```

## 获取文档详情

```
GET /itr/documents/{id}
```

## 更新文档

```
PATCH /itr/documents/{id}
```

## 删除文档

```
DELETE /itr/documents/{id}
```
