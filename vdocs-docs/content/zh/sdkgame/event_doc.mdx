## 2. 发送到 Vlive Tracking 的事件（Hub Logs Collection）

目前发送到 Vlive 的事件参数缺失或按照 Hub Logs Collection 文档来看参数较少。尚未应用的新事件需要补充并重新统一。

### 发送事件到 Vlive tracking game sdk 时的默认参数

- `deviceId` : 设备识别 ID
- `deviceModel` : 设备型号名称
- `deviceBrand` : 设备品牌
- `deviceFullInfoJson` : 设备完整信息（JSON 格式）
- `deviceOs` : 设备操作系统名称（例如：Android、iOS）
- `deviceOsVersion` : 设备操作系统版本
- `appClientId` : 应用 client ID
- `appId` : 应用 ID
- `appName` : 应用名称
- `appCode` : 应用代码
- `appPackage` : 应用 package 名称（例如：`com.example.app`）
- `appVersion` : 应用版本
- `appSdkVersion` : 应用 SDK 版本

`deviceFullInfoJson` 包含以下参数：

- `width` : 屏幕宽度（px）
- `height` : 屏幕高度（px）
- `density_dpi` : 屏幕像素密度（DPI）
- `density` : 屏幕缩放比例（例如：2.0、3.0）
- `serial` : 设备序列号
- `model` : 设备型号名称（例如：Pixel 8、SM-A525F）
- `id` : 操作系统构建 ID
- `manufacture` : 设备制造商（三星、小米、Oppo 等）
- `brand` : 设备品牌
- `type` : 操作系统构建类型（`user`、`userdebug`、`eng`）
- `user` : 用于构建操作系统的用户名
- `base` : 首个 Android 平台版本代码（通常为 1）
- `incremental` : 操作系统递增构建代码
- `sdk` : Android API Level（例如：34）
- `board` : 设备主板/硬件名称
- `host` : 用于构建操作系统的主机名
- `fingerprint` : 设备/ROM 版本唯一标识字符串
- `version_code` : 显示给用户的 Android 版本（例如：14）
