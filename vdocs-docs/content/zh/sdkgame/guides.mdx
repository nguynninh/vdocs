# VTV Live Android 游戏 SDK 开发者指南\.

# 必读更新说明



1. Google Play 16 KB 兼容性要求：
从2026年8月31日起，所有提交至 Google Play 的新应用以及针对现有应用的更新，若目标为 Android 16 \(或更高版本\)，都必须支持64\-bit设备上的16 KB页面大小\.

更多详情，请参见：
     [https://developer\.android\.google\.cn/guide/practices/page\-sizes?hl=zh\_cn\#compile\-16\-kb\-alignment](https://developer.android.google.cn/guide/practices/page-sizes?hl=zh_cn#compile-16-kb-alignment)

2. 根据VTV Live的政策要求，应用内使用的所有URL/链接都必须符合HTTPS标准\.

3. 如果您的unity开发版本为2017\.1或更高，请务必阅读\.
https://discussions\.unity\.com/t/unity\-platform\-protection\-take\-immediate\-action\-to\-protect\-your\-games\-and\-apps/1688031

## 初始化SDK \(必填\)

在您的activity中实现回调AuthenticationListener、PaymentListener

更改环境变量：
Dev \-\> vLiveSdkGame\.setEnvironment\(EnvironmentSdk\.*Development*\);
Prod \-\> vLiveSdkGame\.setEnvironment\(EnvironmentSdk\.*Production*\);

```Java
public class MainActivity extends Activity implements AuthenticationListener, PaymentListener {
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        requestWindowFeature(Window.*FEATURE_NO_TITLE*);
        super.onCreate(savedInstanceState);
        setContentView(R.layout.*activity_main*);
        getWindow().setFlags(WindowManager.LayoutParams.*FLAG_FULLSCREEN*, WindowManager.LayoutParams.*FLAG_FULLSCREEN*);

        // this config sdk game
        VLiveSdkGame vLiveSdkGame = VLiveSdkGame.*getInstance*();
        vLiveSdkGame.setEnvironment(EnvironmentSdk.*Development*);
        vLiveSdkGame.setActivity(this);
        vLiveSdkGame.setAuthenticationListener(this);
        vLiveSdkGame.setPaymentListener(this);


    }

    @Override
    public void onLoginSuccessful(UserInfo userInfo, String accessToken, String refreshToken, String idToken) {
    
    }

    @Override
    public void onLogoutSuccessful() {

    }

    @Override
    public void onPayProductSuccess(String orderId,String productId) {

    }

    @Override
    public void onPayProductError(String error) {

    }
}
```

## SDK功能

### 身份验证 \(必填\)

#### 登录

功能说明：

- 未登录时打开登录界面

- 用户重新打开应用程序时登录

- 登录会话结束时退出登录\.

您应在点击游戏的开始按钮时调用此函数\.

```Java
VLiveSdkGame.*getInstance*().login(); 
```

登录成功将调用onLoginSuccessful



#### 退出登录

退出登录成功将调用onLogoutSuccessful

```Java
VLiveSdkGame.*getInstance*().logout();
```



### 支付 \(必填\)

注：除非您的应用是通过Google Play的内部测试通道安装的，否则无法测试支付功能\.

要进行支付测试，我们需要AAB \(Android App Bundle\) 版本\.

#### 应用内购买 \(IAP\) 游戏礮包清单 \( **可选 **\)

此功能将返回类似于**Pricelist\.xlsx**文件的充值礮包列表\.
注：这是一个可选功能，可根据需要调用\.

```Java
List<ProductInfo> listProduct = VLiveSdkGame.*getInstance*().getListProduct();
```

Model ProductInfo

```Java
String productId = productInfo.getProductId(); // vn.vplay.game.t001a.029
String productName = productInfo.getProductName(); // 20 Ngân Phiếu
```



#### 购买礮包 \(必填\)

如果您想购买某个物品，请调用此函数：

输入参数可从上方列表中获取，也可手动输入\.

```Java
String productId = "vn.vplay.game.t001a.029"; 
String characterId = "324132321";
String serverId  = "123";
VLiveSdkGame.*getInstance*().payProduct(productId,characterId,serverId);
```



### 事件追踪 \(必填\)

注：用于营销目的的追踪功能应严格按照规定的流程使用\.

#### 以下这些事件为必须集成的事件\.



#### 事**件参数详情**

1. 追踪补丁开始 \(必填\)
描述：应在资源下载开始时调用\.
事件名称：af\_patch\_start

```Java
String patchVersion = "1.1.23"; // or empty
double patchSizeMb = 550.5; // or 0
VLiveSdkGame.*getInstance*().trackingPatchStart(patchVersion,patchSizeMb);
```



2. 追踪补丁错误 \(必填\)
描述：应在资源下载过程中发生错误时调用\.
事件名称：af\_patch\_error

```Java
String cdnIp = "122.56.12.188"; // or empty
String errorCode = "404_NOT_FOUND"; // or empty
String failedUrl =  "https://cdn.game.com/patch/v120.zip"; // or empty
VLiveSdkGame.*getInstance*().trackingPatchError(cdnIp, errorCode,failedUrl);
```



3. 追踪补丁成功 \(必填\)
描述：*应在所有资源成功下载完成后调用\.*
事件名称：af\_patch\_success

```Java
int timeDownloadSecond = 32; // or 0
String cdnIp = "122.56.12.188"; // or empty
double patchSizeMb = 500.5; // or 0
VLiveSdkGame.*getInstance*().trackingPatchSuccess(timeDownloadSecond,cdnIp,patchSizeMb);
```



4. 追踪解压开始 \(必填\)
描述：*应在资源解压过程开始时调用\.*
事件名称：af\_extract\_started

```Java
int totalFiles = 400;// or 0
double totalSizeMb = 500.5;// or 0
VLiveSdkGame.*getInstance*().trackingExtractStart(totalFiles,totalSizeMb);
```



5. 追踪解压完成 \(必填\)
描述：*应在所有资源成功解压完成后调用\.*
事件名称：af\_extract\_finished

```Java
int timeExtractSecond = 32; // or 0
String resultCode = "success" // or Errror String (ex: out_of_storage)
VLiveSdkGame.*getInstance*().trackingExtractFinished(timeExtractSecond,resultCode);
```

6. 追踪显示游戏开始画面 \( 必填\)
描述**：**应在游戏开始画面显示后调用\.
事件名称：af\_show\_start\_game

```Java
VLiveSdkGame.getInstance().trackingEvent(EventGameTracking.EVENT_SHOW_START_GAME);
```

7. 追踪服务器选择 \( 必填\)
描述**：***应在用户确认服务器选择并进入游戏流程后调用\.*
事件名称：af\_server\_select

```Java
String serverName = "ServerName"; // Required Not empty, Not Null 
String serverId = "23232"; // Required Not empty, Not Null 
VLiveSdkGame.*getInstance*().trackingServerSelected(serverName,serverId);
```

8. 追踪角色创建开始 \( 必填\)
描述**：***应在角色创建界面对用户可见时调用\.*
事件名称：af\_char\_create\_start

```Java
VLiveSdkGame.getInstance().trackingCharacterCreationStart();
```



9. 追踪角色创建错误 \( 必填\)
描述**：**应在角色创建过程中发生错误时调用\.
事件名称：af\_char\_create\_error

```Java
String characterNameError = "Hao Thien"; // or empty
String errorMessage = "NAME_DUPLICATED"; // or empty
VLiveSdkGame.*getInstance*().trackingCharacterCreateError(characterNameError, errorMessage);
```



10. 追踪角色创建完成 \( 必填\)
描述**：***应在角色创建流程成功完成后调用\.*
事件名称：af\_char\_create\_success

```Java
String characterName = "CharacterName"; // *Required Not empty, Not Null *
String characterId = "23232"; // *Required Not empty, Not Null *
VLiveSdkGame.*getInstance*().trackingCharacterCreationComplete(characterName,characterId);
```



11. 追踪角色选择 \( 必填\)
描述**：**应在用户选择现有角色并进入游戏后调用\.
事件名称：af\_char\_select

```Java
String characterName = "CharacterName"; // Required Not empty, Not Null 
String characterId = "23232"; // Required Not empty, Not Null 
String characterLevel = "1"; // Required Not empty, Not Null 
VLiveSdkGame.*getInstance*().trackingCharacterSelected(characterName,characterId,characterLevel);
```



12. 追踪进入游戏 \( 必填\)
描述**：**应在用户已选择角色并开始进入游戏后调用\.
事件名称：af\_enter\_gameplay



```Java
VLiveSdkGame.getInstance().trackingEvent(EventGameTracking.EVENT_GAME_ENTER);
```



13. 映射用户 \( 必填\)
描述**：**应在用户已选择角色并开始进入游戏后调用\.
事件名称：af\_level\_achievement

```Java
String characterName = "CharacterName"; // or empty
String characterId = "23232"; // Required Not empty, Not Null 
String characterLevel = "2"; // Required Not empty, Not Null 
String serverName = "ServerName";// or empty
String serverId = "324232";// Required Not empty, Not Null 
VLiveSdkGame.*getInstance*().mapUser(characterName, characterId, characterLevel, serverName, serverId);
```



14. 角色升级 \( 必填\)
描述**：***应在用户成功升级时调用\.*
事件名称：af\_level\_achievement
事件名称：af\_vip\_achievement

```Java
String characterName = "CharacterName"; // or empty
String characterId = "23232";// Required Not empty, Not Null 
String characterLevel = "2"; // Required Not empty, Not Null 
String serverName = "ServerName"; // or empty
String serverId = "324232"; // or empty
String vip = "1"; // Required Not empty, Not Null 
VLiveSdkGame.*getInstance*().levelUpUser(characterName, characterId, characterLevel, serverName, serverId,vip);
```



15. 追踪加载游戏地图 \( 必填\)
描述**：***应在地图完全加载完成后调用\.*

```Java
String mapId = "newbie_village"; // or empty
int timeLoadSecond = 32; // or 0
int fpsAtStart = 60; // or 0
VLiveSdkGame.*getInstance*().trackingMapLoad(mapId, timeLoadSecond, fpsAtStart);
```

16. 自定义事件
描述**：**用于其他自定义事件

```Java
String eventName = "Event_Name";
VLiveSdkGame.*getInstance*().trackingEvent(eventName);

// Or
String eventName = "Event_Name";
JsonObject jsonObject = new JsonObject();
jsonObject.addProperty("stringValue", "Hello");
jsonObject.addProperty("intValue", 42);

```
