# Update SDK 5.0.0

变更历史：

- 更新 platform iOS 15

- 更新 Firebase 12.0.0

- 更新 AppsFlyerFramework 6.17.2

- 更新 tracking

- 新增 FirebaseCrashlytics 12.0.0

1. PodFile

```Swift
platform :ios, '15.0'
target 'SdkExample' do
  use_frameworks!
  pod 'GoogleSignIn', '7.1.0'
  pod 'Firebase', '12.0.0'
  pod 'FirebaseMessaging', '12.0.0'
  pod 'FirebaseRemoteConfig', '12.0.0'
  pod 'AppsFlyerFramework', '6.17.7'
  pod 'JWT', '2.2.0'
  pod 'TikTokBusinessSDK', '1.5.0'
  pod 'FirebaseRemoteConfig', '12.0.0'
end
target 'FirebaseNotificationServiceExtension' do
 use_frameworks!
 pod 'Firebase', '12.0.0'
 pod 'FirebaseMessaging', '12.0.0'

end
post_install do |lib|
    lib.pods_project.targets.each do |target|
        if target.name == 'GoogleSignIn' || target.name == 'Firebase' || target.name == 'FirebaseRemoteConfig' || target.name == 'FirebaseMessaging' || target.name == 'AppsFlyerFramework' ||  target.name == 'JWT' ||  target.name == 'TikTokBusinessSDK'
            target.build_configurations.each do |config|
                config.build_settings['BUILD_LIBRARY_FOR_DISTRIBUTION'] = 'YES'
            end
        end
        
        target.build_configurations.each do |config|
            config.build_settings['IPHONEOS_DEPLOYMENT_TARGET'] = '15.0'
        end
    end
end
```

4. Update log（更新日志函数）

调用 **logStartedCharacterCreation** 或 **logFinishedCharacterCreation** 时，您需要附加以下参数：

- 对于 **logStartedCharacterCreation**，请提供 **serverId** 和 **serverName**。

- 对于 **logFinishedCharacterCreation**，请提供 **characterId** 和 **characterName**。

```Swift
-(void) logStartedCharacterCreation:(NSString *) serverId withSeverName: (NSString *) serverName;
-(void) logFinishedCharacterCreation:(NSString *) characterId characterName :(NSString*)characterName;
```
