2. 登录

```mermaid
flowchart LR
    A(("点击登录")) --> B["检查维护状态"]
    B --> C{"状态"}
    C -- "yes" --> Z(("停止登录"))
    C -- "no" --> E{"是否有 access token"}
    E -- "no" --> D["打开登录界面"]
    E -- "yes" --> F["获取用户信息"]
    D --> G["登录账号，<br/>Google/Facebook，注册"]
    G --> H["登录"]
    H --> I["登录成功"]
    F --> J{"通过 access<br/>token 获取信息"}
    J -- "access token 未过期" --> I
    J -- "access token 已过期" --> K{"刷新<br/>access token"}
    K -- "成功" --> I
    K -- "失败" --> L["登出<br/>清除登录信息<br/>及各类 token"]
    L --> Z
    I --> M["开始游玩时长计时<br/>埋点留存<br/>推送 FCM token 至服务器<br/>认证<br/>获取充值套餐列表<br/>请求通知权限<br/>埋点登录事件"]
    M --> N{"检查等级<br/>是否需要补充<br/>用户信息"}
    N -- "等级 1" --> O{"显示可关闭的<br/>补充信息<br/>界面"}
    O -- "更新成功" --> S(("登录完成"))
    O -- "已关闭" --> S
    N -- "等级 2" --> P["显示不可关闭的<br/>补充信息界面"]
    P -- "成功" --> S
    N -- "等级 0" --> S
```

C. 支付

```mermaid
flowchart LR
    A(("登录成功")) --> B["从 hub<br/>获取充值套餐列表"]
    B --> C["从商店获取套餐<br/>并与 hub 的<br/>套餐比对"]
    C --> D(("可购买的<br/>套餐列表"))
    E(("购买套餐")) --> F{"购买前<br/>检查"}
    F -.- G["billingClient 就绪<br/>套餐列表非空<br/>网络已连接<br/>套餐及角色信息<br/>非空<br/>正在支付状态为 true"]
    F -- "false" --> H["停止支付<br/>关闭 fragment<br/>正在支付状态<br/>为 false"]
    F --> I["打开支付 fragment"]
    I --> J{"初始化<br/>API 交易"}
    J -- "失败" --> H
    J -- "成功" --> K{"重新检查<br/>套餐及<br/>billingClient"}
    K -- "false" --> H
    K -- "true" --> L["打开商店支付界面<br/>并等待用户<br/>完成支付"]
    L --> M{"交易<br/>状态"}
    M -- "等待支付（交易<br/>较慢）" --> N["显示提示，要求<br/>完成交易"]
    N -- "等待交易" --> M
    M -- "未知错误" --> H
    M -- "已支付" --> O["PURCHASED<br/>已支付"]
    O --> P["发送消费验证"]
    P --> Q{"消费<br/>状态"}
    Q -- "失败" --> R["该套餐已被验证<br/>为已消费，但在<br/>返回结果过程中<br/>断开了连接"]
    R --> S["显示提示，要求<br/>联系热线支持"]
    S --> H
    Q -- "消费成功" --> T["调用 API 为游戏充值"]
    T --> U{"API 状态"}
    U -- "失败" --> V{"显示重试<br/>弹窗"}
    V -- "失败" --> S
    V -- "成功" --> W(("游戏充值<br/>成功，交易<br/>完成"))
    U -- "成功" --> W
```
