# 更新 play_time 事件调用逻辑

## 目的

## 需求

1. 登录成功后，按周期 30 秒、1 分钟、3 分钟、5 分钟、15 分钟、30 分钟、1 小时触发，此后每 1 小时定期触发一次。

2. 如果角色创建成功，则将 play time 重置为 0，并按 (1) 重新计算。

3. 如果用户跨天游玩，到 UTC+7 时间 0:00 时会自动将 play time 重置为 0，并按 (1) 重新计算。

4. 如果用户返回主页 -> 暂停 play_time -> 用户在未被登出的情况下重新进入游戏 -> 从暂停时刻继续计算 playtime。

5. 如果用户返回主页后，再次进入游戏时已被登出，则从 (1) 重新计数。
